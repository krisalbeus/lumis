gesture 12. Gesture Engine & Undo Transaction Contract

Atomic Stack Rule
1
ACTION_DOWN / Gesture Begin Capture Initial State

Touch down within 48dp radius locks target vertex. System records snapshot of current 3x3 homography matrix & vertex coords V_start(x,y).

2
ACTION_MOVE / Real-time Drag 60fps OpenGL Delta

Vertices stream real-time updates directly to GL surface buffer without creating history nodes. UI updates coordinates HUD without garbage collector allocation.

3
ACTION_UP / Gesture End 1 Undo Entry Only

Strict Single Transaction: The entire drag gesture commits exactly ONE atomic entry to the undo stack containing delta(V_start → V_end). Pressing Undo reverts the corner in a single tap.

Autosave timer resets after each ACTION_UP event, coalescing flash writebacks to a 30-second throttle.
